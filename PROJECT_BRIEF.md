# Project Brief — VectorGlyphs

## One-line concept

Generate beautiful circular vector glyphs for modern digital products.

## Product

VectorGlyphs is a professional web tool for generating premium procedural glyphs and exporting them as SVG and high-resolution PNG assets. It targets practical production use: UI components, app visuals, landing pages, dashboards, onboarding screens, empty states, presentation markers, and brand exploration.

## Domain and brand

- Primary domain: `vectorglyphs.com`
- Brand tone: premium, minimal, professional, fast, useful, credible
- Avoid: generic AI-art positioning, overclaiming uniqueness, playful/toy-like design

## Target users

Primary:

- Indie hackers and founders
- UI/UX designers
- Developers
- Digital product creators
- Agencies and freelancers

Secondary:

- Brand identity designers
- Presentation creators
- Figma/Webflow/Framer users
- Wellness/mindfulness app makers
- AI/crypto/quant dashboard builders

## MVP promise

- Preview generated glyphs for free.
- Choose style, complexity, stroke, palette, background, format, and PNG size.
- Pay a small fixed price for production-ready downloads.
- Receive SVG/PNG/ZIP exports with a simple commercial-use license.

## MVP must include later

- Professional landing page with live generator.
- Seed-based deterministic generation.
- Preview grid and selected glyph preview.
- SVG, PNG, and ZIP export after payment.
- `$1` single-glyph download path.
- Stripe Checkout and webhook-confirmed unlocking.
- Success page with tokenized download link.
- Feedback form forwarding to Telegram when configured.
- SEO-friendly sections, metadata, FAQ, and structured content.
- Docker deployment path for LAN host + Cloudflare Tunnel.

## Explicitly out of MVP

- User accounts.
- Complex dashboard.
- Public user gallery requiring moderation.
- PayPal.
- Subscriptions.
- Arbitrary user-uploaded SVG.
- Heavy DRM.
- Over-engineered queue/worker systems.
