# Marketing Plan — VectorGlyphs

## Positioning

VectorGlyphs is a premium procedural vector glyph generator for apps, UI, logos, dashboards, landing pages, and digital products.

Avoid positioning as a generic AI-art toy. Emphasize:

- procedural generation
- SVG/PNG export
- deterministic seeds
- design-system usefulness
- commercial-use assets
- fast preview-to-download flow

## Landing page copy foundation

SEO title:

> Vector Glyph Generator — Create SVG & PNG Glyphs Online

Meta description:

> Generate beautiful circular vector glyphs for apps, websites, logos, UI and digital products. Preview for free, download SVG or high-resolution PNG for $1. Commercial license included.

H1:

> Vector Glyph Generator

Hero copy:

> Create unique circular SVG and PNG glyphs for apps, websites, logos, dashboards and digital products. Preview for free. Download production-ready files for $1.

Hero microcopy:

> No signup required. Commercial license included. SVG and transparent PNG exports.

## Content pillars

1. UI inspiration: empty states, onboarding cards, SaaS feature sections, dashboards.
2. Design utility: SVG vs PNG, simple glyphs in product identity, app icon/brand exploration.
3. Generated examples: daily glyph, generated packs, app/dashboard mockups.
4. Build in public: progress, traffic/revenue learnings, generated designs.

## Platform strategy

Start with low-risk channels:

- Own website gallery/blog pages.
- Pinterest after API/scheduler/automation feasibility is checked.
- X/Twitter if API or safe browser automation is acceptable.
- GitHub examples/open design assets.
- Figma Community after requirements research.
- Dribbble and Behance after upload/API/browser automation feasibility and account-safety checks.

## Visual marketing outbox shape

Future marketing runs should write:

```txt
marketing/outbox/<date-slug>/image.png
marketing/outbox/<date-slug>/caption.md
marketing/outbox/<date-slug>/alt-text.md
marketing/outbox/<date-slug>/metadata.json
marketing/outbox/<date-slug>/source.html
```

Publishing should remain disabled until accounts, credentials, platform rules, and approval policy are explicitly configured.

## Quality gate

Before any public publishing, verify:

- visual polish
- legibility
- no broken layout
- glyph visibility and attractiveness
- domain/caption present but not obnoxious
- no hallucinated UI claims
- no trademark/copyrighted brand imitation
- no spammy hashtags
